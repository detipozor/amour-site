Порядок важности, если источники расходятся:

## 1. Стек и решения

| Что | Решение | Почему |
|---|---|---|
| CMS | WordPress, своя тема с нуля (классическая тема на PHP-шаблонах) | Решение 30.10 (док. 09). Старый сайт тоже на WordPress |
| Поля админки | Secure Custom Fields (бесплатный, с WordPress.org): повторители, гибкий контент, страницы настроек. Запасной вариант — ACF Pro | Нужны повторители и страница настроек без платного плагина. Платные плагины — только с согласия Костянтина |
| Языки | Polylang (бесплатный). EN основной, DE вторым, адреса `/de/…`, hreflang | Мультиязычность закладываем сразу (док. 09, п. 3) |
| Анимации | Ванильный JS, как в прототипе (`design/js/amour-live.js`, логика в досках). При необходимости — GSAP с ScrollTrigger: он стал бесплатным и для коммерческих проектов | Без тяжелых зависимостей; один модуль на блок |
| Формы | Своя форма с проверкой полей (как в макете) + отправка через `wp_mail` и SMTP-плагин; от спама — скрытое поле и Cloudflare Turnstile после согласия | Без лишних данных (чек-лист п. 7) |
| Карты | Свои SVG-карты рельефа из ассетов, без встраивания Google Maps; ссылки «Open in Google Maps» ведут наружу | Не нужно согласие на cookie для карты |
| Бронь | Движок BookOnlineNow через HotelAvailabilities (HA). Оплата 100% при брони — внутри движка | Своей оплаты на сайте нет. См. раздел 7 |
| Хостинг | Текущий хостинг боевого сайта amourrelaxhotel.com (по DNS — Hosting Ukraine, уточнить в панели). Тестовая копия — чистый WordPress с отдельной базой на поддомене этого же хостинга; при запуске она заменяет старый сайт на основном домене. Проверить: PHP 8.2+, SSH, поддомены, бэкапы | Домен и DNS не меняются. Аккаунт хостинга и регистратора — перевести на компанию (док. 01, раздел 6) |
| Локальная разработка | wp-env (Docker Desktop): WordPress, PHP 8.2, MySQL; та же среда в GitHub Actions | Решение 19.11: база как на хостинге, одна среда для разработки и автотестов |
| Репозиторий | Публичный репозиторий на GitHub (решение 19.11): личный аккаунт Костянтина, после запуска — по желанию перенос в организацию компании (Settings → Transfer). Сайт живет на хостинге, GitHub — код, тесты и справочные материалы (доски, прототип, скриншоты, ассеты, доки). На хостинг выкладываются только тема (`wp-content/themes/amour`) и mu-plugin. Без паролей, ключей, данных гостей и внутренних документов: ключи — в секретах GitHub и `wp-config.php` вне репозитория, внутреннее — в папке `private/` вне Git; коммиты — со скрытым адресом GitHub | История правок, автотесты, превью Playground и выкладка на тест из одного места (раздел 18) |

## 6. Страницы: блоки и поведение

Подробная раскладка — в досках. Здесь то, чего из статичной доски не видно.

### Главная (Main-v2 + Main-v2-b)
1. **Первый экран.** Арка с видом сверху на отель, крупно AMOUR (картинка логотипа), строка «A nine-room hotel…», «Check dates». При прокрутке 0–520 px экран закреплен: арка раскрывается на весь экран (скругление 260 → 0), шапка и AMOUR становятся известковыми, на видео затемнение 0 → 36%, кривая с плавным стартом и финишем. Видео `home-hero-video.mp4`, сначала показываем постер.
2. **Поиск дат** (раздел 5).
3. **Фраза** на винном блоке «Nine rooms among olive groves…»: слова загораются по мере прокрутки, 18% → 100%. При «уменьшить движение» — целиком сразу.
4. **The estate:** фото со скругленным верхом растет с половины ширины до полной, скругление 170 → 22 px, заголовок уходит вверх на 36 px. Привязано к прокрутке.
5. **A day at Amour:** лента арок, центральная — цветная арка, остальные приглушены (серый + сепия). Смена кадра по прокрутке, мягкая S-кривая и легкая инерция, чтобы колесо не дергало картинку. Подписи: время дня + фраза. Время заката считается живым расчетом для Альмириды (функция в доске).
6. **Номера:** «Stay like you live here», сетка номеров. На десктопе при наведении меняется кадр карточки. На телефоне — высокие фото 4:5 с параллаксом, без смены кадра, факты отдельной строкой под названием.
7. **Переход к вилле «Room for everyone»:** фото растет в арку, слева и справа въезжают слова, фон переходит в палитру виллы (круг цвета пены растет из арки и заливает блок). Затем «Five bedrooms, one long table».
8. **Карта:** три шага при прокрутке — весь Крит → Альмирида с точками отеля и виллы → «Day trips»; вкладки внизу (The hotel / Villa Eudora / Day trips) в одну строку.
9. **Отзывы** (раздел 5).
10. **Book direct:** «Same price, straight to us», ссылка на бронь.
11. **Футер.**

На телефоне закреплены только первый экран и раскрытие виллы, остальное — обычная прокрутка.

### Страница номера (Room-*, шаблон из `design/generators/room_template.html`)
1. Винный экран: огромное имя номера стоит, фото по очереди едут поверх слева и справа, каждое входит аркой и при подъеме раскрывается в прямоугольник 24 px; подпись и счетчик «1 / 6». На телефоне имя по ширине экрана, фото — лента пальцем (поток как у Casa Momo: 72vw, горизонтальные 86vw).
2. Цвет фона перетекает из винного в известь, когда поднимаются детали (на телефоне позже, с 55% высоты экрана).
3. «Room details»: описание крупно, 6 главных фактов, остальное по кнопке «All details».
4. Карта окрестностей с временем в пути и карточкой «Almyrida, Crete».
5. «Other ways to stay» — лента карточек.
6. Плашка цены внизу.

### Вилла (Villa-v2 + Villa-v2-b)
Тот же принцип в палитре виллы. Плюс: «The house» с фактами, «Five bedrooms» (лента карточек спален), «How the house works» (схема этажей — заглушка до плана архитектора), «Long tables, long evenings» (праздники и свадьбы: «Plan a gathering», WhatsApp), карта, «Or stay at the hotel», футер с кувшинами. Расстояние до моря — «about 250 m» (проверенный факт).

### Court and pool (Estate)
Первый экран «Game, set, sunset» с видео корта и слайдером «день → ночь»; строка фактов о корте; «Book a court slot on WhatsApp». Бассейн: «Quiet days by the water», три пункта (Sunbeds, Daybeds, Lit after dark) по прокрутке меняют фото, текущий пункт ярче, остальные с прозрачностью 0,85 (контраст AA). Вид территории сверху с маркерами. Финал «Pack a swimsuit, leave the racket».

### Crete guide (Guide)

## 7. Бронь и оплата

**Как сейчас в макете (`/book/`, доска Book):** 4 шага — 1 Dates, 2 Room, 3 Details, 4 Payment. Шаг 1: поля Arrive / Leave (свой календарь) и Guests (−/+). После поиска — список свободных вариантов: три типа номеров и вилла, у каждого цена за все ночи, строка «Free cancellation until [14] days before arrival · climate fee paid at the hotel», кнопка Select. Варианты, где вместимость меньше числа гостей, скрыты. Справа сводка, «Change dates or room». Цены в макете — пример из предложения на 2027 год, на сайте их дает движок.

**Как на сайте.** Оплата 100% при брони, внутри BookOnlineNow (через HA). Способ подключения движка неизвестен — вопрос 3 к поддержке HA (211 500 7007, доб. 2):
- **Если у движка есть API доступности и цен** — шаги 1–2 наши (как в макете), шаги 3–4 — экраны движка (переход с параметрами дат, гостей и номера).
- **Если только виджет или ссылка** — наш шаг 1 (даты, гости) передает параметры в движок, дальше все в движке. Шаг 2 тогда тоже движка.
- Возврат после оплаты — на `/thank-you/` с номером брони, если движок это поддерживает.
- Вилла: один движок или два — зависит от того, станет ли вилла отдельным объектом в HA (вопрос 4).
- До ответа HA: собрать шаги 1–2 с моковыми данными за интерфейсом `BookingProvider` (`search(dates, guests) → units[]`, `handoff(unit) → url`), чтобы потом заменить только реализацию.

**Правила цены:** полная цена видна сразу; климатический сбор — отдельной строкой «paid at the hotel»; условия отмены — рядом с ценой и галочка согласия перед оплатой; без «осталась 1 комната», таймеров и заранее выбранных допуслуг (чек-лист п. 3, 9, 10).

## 11. Как читать доски

Каждая доска — HTML-файл формата Design canvas:
- `<x-dc>…</x-dc>` — шаблон страницы. `{{name}}` — значение из логики, `<sc-for list="{{items}}" as="item">` — цикл.
- `<x-import component-from-global-scope="Amour.Footer" …>` — компонент из `design/ds/components/bundle.js` (Button, Icon, Footer и др.).
- `<script type="text/x-dc">class Component extends DCLogic {…}</script>` — логика: `renderVals()` возвращает значения для шаблона, `componentDidMount` вешает обработчики прокрутки. Все расчеты анимаций (прогресс по прокрутке, кривые, размеры) — здесь, их переносим в JS-модули темы.
- `/_blob/<id>` — картинка, файл ищем в `assets/manifest.csv`.
- Классы `.v2`, `.ph-only`, `.dk-only` и правила телефона — в `design/css/amour-soft.css`.
- Генераторы страниц номеров, виллы и служебных страниц (`design/generators/*.py`) содержат данные номеров и тексты в удобном виде — брать данные оттуда.
- Оболочка прототипа (`design/prototype-shell/app.js`, `build_site.py`) показывает, как работают шапка, меню, переходы между страницами и «soft dissolve».

## 15. Проверка готовности

- совпадает со скриншотами на 1440 и 390 и следует правилу планшета;
- нет прокрутки вбок на 360–1440;
- проверка axe без серьезных нарушений (кроме промежуточных кадров анимации);
- все работает с клавиатуры и при «уменьшить движение»;

- формы: пустая отправка показывает ошибки и ставит фокус, заполненная — сообщение;
- меню открывается и закрывается Esc;
- отзывы встают на паузу;
- axe на каждой странице;
- Lighthouse на главной, номере и брони: телефон, скорость от 85, доступность от 95.
