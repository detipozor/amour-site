# CLAUDE.md — сборка сайта Amour Relax Hotel + Villa Eudora

Ты собираешь собственную тему WordPress по готовым макетам. Полное задание — `HANDOFF.md`, прочитай его целиком перед первым шагом.

## Где что лежит
- `HANDOFF.md` — задание: стек, страницы и адреса, токены, брейкпоинты, компоненты, бронь, формы, админка, доступность, тесты, этапы.
- `design/boards/*.dc.html` — доски с холста: точная разметка, тексты и логика анимаций. Главный источник правды (формат — HANDOFF, раздел 11).
- `prototype/Amour-site-prototype.html` — рабочий прототип всех страниц, открывается в браузере. Поведение смотри здесь.
- `screens/desktop`, `screens/phone` — эталонные скриншоты 1440×900 и 390×844, сверху вниз по каждой странице.
- `design/ds/tokens.css`, `design/css/*.css`, `design/js/amour-live.js` — токены, телефонный слой, анимации.
- `design/generators/*.py` — данные номеров, виллы и служебных страниц.
- `assets/images` + `assets/manifest.csv` — картинки, видео и SVG; id из досок (`/_blob/<id>`) → файл, alt, где используется.
- `assets/fonts` — Instrument Sans и Tenor Sans (woff2, OFL).
- `docs/` — бренд-мануал (08), решения и открытые вопросы (09, публичная версия), аудиты (12, 13), список заглушек.
- `private/` — внутреннее, только на Mac Костянтина и не в Git: полная версия дока 09 (номера аккаунтов, бюджет, служебные пометки) и прочее, что нельзя показывать.

## Правила бренда (нельзя нарушать)
- Имя: **Amour Relax Hotel** и **Villa Eudora**. В логотипах — только SVG из пакета, не набирать шрифтом.
- Тексты для гостей — английский (основной) и немецкий. Голос — заботливый хозяин: спокойно, конкретно, тепло.
- Никогда: «adults only», «breakfast included», «luxury», «paradise», «hidden gem», «в шаге от моря». Отель принимает всех; «recommended for guests 12+» — правило дома. Завтрака нет: номер с кухней + корзина от пекарни-партнера.
- Только проверенные цифры: пляж Альмириды 1,2 км, Ханья 23 км, вилла ≈250 м до моря, ≈4 минуты от отеля и до 11 гостей.
- Шрифты — только Instrument Sans и Tenor Sans (Tenor — только прописные надписи до 4 слов). Без курсива.
- Цвета — только через токены. Без сине-белого «Санторини», меандра, колонн, античных статуй, псевдогреческих букв, градиентов, #FFF и #000.
- Фото — только свои из `assets/images`. Не брать стоки, фото с Booking и чужие картинки.
- Отзывы — только реальные с Booking дословно, со ссылкой на источник. Не выдумывать.
- Заглушки в квадратных скобках (`[price]`, `[Phone]`…) не придумывать: это поля админки, их заполнят при наполнении.

## Как работать
- Иди по этапам из HANDOFF, раздел 17. Компонент за компонентом; каждый сверяй со скриншотами на 1440 и 390 и проверяй на 768 и 1024.
- Логику анимаций переноси из `renderVals()` досок в JS-модули темы; соблюдай `prefers-reduced-motion`.
- Тексты, цены, фото и настройки — из админки (HANDOFF, раздел 9), не зашивай их в шаблоны.
- Бронь собирай за интерфейсом `BookingProvider` (HANDOFF, раздел 7): сначала мок, потом реальный движок.
- Не добавляй платные плагины и внешние сервисы без согласия Костянтина. Сторонние скрипты — только после согласия на cookie.
- Репозиторий публичный: его видят все. Никаких паролей, ключей и токенов (ключи — в `wp-config.php` или `.env` вне Git, для Actions — в секретах GitHub), данных гостей, личных почт, номеров аккаунтов, бюджета и внутренних пометок — такое кладем в `private/`. Коммиты — со скрытым адресом GitHub (`…@users.noreply.github.com`), не с личной почтой.
- Код живет в публичном репозитории GitHub `detipozor/amour-site` (https://github.com/detipozor/amour-site, личный аккаунт Костянтина; публичный с 19.11.2026), сайт выкладывается на текущий хостинг amourrelaxhotel.com: сначала тестовый поддомен, при запуске основной домен (HANDOFF, раздел 18): ветка на задачу, pull request, автотесты в GitHub Actions, слияние в `staging` выкладывает на тест. В `main` и на боевой сайт — только по команде Костянтина.
- Маленькие коммиты с понятными сообщениями. Перед каждым коммитом — автотесты из HANDOFF, раздел 15.
- Если в досках и HANDOFF есть расхождение или не хватает данных — спроси, не угадывай.

## Готово, когда
Страница совпадает со скриншотами, нет прокрутки вбок на 360–1440, axe без серьезных нарушений, все работает с клавиатуры и при «уменьшить движение», содержимое берется из админки, автотесты зеленые.
