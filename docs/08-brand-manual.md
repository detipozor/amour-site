## 4. Шрифты

_Решение 19.11.2026: вариант 3 из сравнения, проверен по правилам UI UX Pro Max. Заменяет пару Tenor Sans + Jost._

- **Instrument Sans** — все, что гость читает: заголовки, текст, меню, кнопки, цены, подписи. Обычный регистр, без прописных. Вариативный шрифт: толщина 400–700, ширина 75–100.
- **Tenor Sans** — только короткие надписи над заголовками и подписи (до 4 слов): прописными, с разрядкой .16–.2em, 12–13 px, толщина 400. Повторяет подпись RELAX HOTEL в логотипе. Не для кнопок, ссылок и предложений.
- **Cormorant Garamond** на сайт не подключаем: он живет только внутри SVG логотипов и в счет шрифтов сайта не идет.
- **Jost больше не используем.**
- Без курсива и рукописных шрифтов.
- Лицензия SIL OFL, оба шрифта есть в Google Fonts: `family=Instrument+Sans:wdth,wght@75..100,400..700&family=Tenor+Sans`.
- **Языки:** в Instrument Sans есть латиница и расширенная латиница (английский, немецкий, польский), кириллицы и греческого нет. Греческий для вывески, если его потребует закон, — Manrope.

| Элемент | Шрифт | Десктоп / мобильный |
|---|---|---|
| H1 | Instrument Sans 400, разрядка −.03em, интерлиньяж 1,05 | 72 / 40 px |
| H2 | Instrument Sans 400, −.025em, 1,1 | 44 / 30 px |
| H3, название номера и карточки | Instrument Sans 500, −.01em, 1,2 | 24 / 20 px |
| Крупная фраза на темном блоке | Instrument Sans 400, −.025em, 1,1 | 76 / 44 px |
| Надстрока, короткая подпись | Tenor Sans 400, прописные, .2em | 13 / 13 px |
| Текст | Instrument Sans 400, разрядка штатная, интерлиньяж 1,6 | 18 / 16 px |
| Цена, детали | Instrument Sans 500 | 16 px |
| Кнопка, меню, ссылка | Instrument Sans 500, обычный регистр | 15 px |

**Правила:**
- прописные — только Tenor и только до 4 слов;
- сжатая разрядка — только у заголовков от 20 px, у текста разрядка штатная;
- строка текста — 65–75 знаков на десктопе;
- иерархию строим размером и толщиной, а не регистром.

## 5. Компоненты и сетка

- **Стиль:** плоско, спокойно, много воздуха. Без скруглений и теней. Тень допустима только у выпадающих элементов: поиск дат, меню.
- **Кнопки:**
  - основная — заливка терракотой, текст известью;
  - вторичная — контур терракотой;
  - на фото — контур известью;
  - при наведении фон темнеет на 8%.
- **Поиск дат.** На главной — плашка поверх первого экрана: Arrive / Leave / Guests / Check dates; календарь свой, на английском. На мобильном кнопка брони закреплена внизу экрана.
- **Карточка номера.** Фото 3:2, над названием надстрока Tenor («ROOM 01»), название Instrument Sans 500, строка деталей вида «Kitchen · terrace · 2 guests», цена «from €110 / night», ссылка «View room».
- **Арка** — фирменная рамка для фото, верх полукругом. Не больше одной арки на экран.
- **Сетка:** шаг 8 px, контейнер 1240 px. Между секциями 96–128 px на десктопе и 64 px на мобильном.
- **Анимации:** только мягкое появление (fade 300–400 мс). Без параллакса, прыжков и автоплея со звуком.
- **Мобильную версию делаем первой:** большинство броней идет с телефона.

## 6. Фото

- **Стиль «Пленка»:**
  - теплый свет золотого часа, длинные тени, легкое зерно;
  - приглушенные синий и зеленый;
  - кадры через дверной проем, люди в движении.
- **Баланс в галереях:** 60% — честная архитектура (номера, вид, бассейн, корт), 30% — настроение, 10% — детали. В галерее номера первые фото — номер целиком, кухня, терраса, вид.
- **Форматы:**

| Где | Формат |
|---|---|
| Первый экран | 16:9, от 2400 px, затемнение 30–45% под текстом |
| Карточки номеров | 3:2 |
| Блок Instagram | 4:5 |
| Арка | 3:4 |

- **Техника:** WebP до 300 КБ, alt-тексты на английском.
- **Пока нет съемки** — серые плашки «Фото после съемки». Не стоки и не чужие фото: референсы из папки «warmphoto reference» — только ориентир.

## 7. Графика

- **Паттерн оливы** (пиктограмма тон в тон, прозрачность 10–15%) — фон темных секций отеля.
- **Паттерн кувшинов** — то же для раздела виллы.
- **Пиктограммы оливы и кувшина** — разделители, иконка брони, пустые состояния.
- **Не используем:**
  - меандр, колонны, античные статуи;
  - сине-белый «Санторини», сердца;
  - псевдогреческие буквы (Σ вместо E, Λ вместо A);
  - стоковые иконки.
