# Пакет логотипов Amour и Eudora

Мастера из `amour_eudora_package.zip`. В Git лежат SVG и фавиконы; PDF для печати и превью PNG остаются только локально (`.gitignore`).

**Проверено 20.11.2026:** логотипы прототипа в `assets/images` геометрически совпадают с этими мастерами (одинаковые контуры). Прототип только убрал фон и перекрасил. В теме берем файлы пакета без фона (`*_transparent.svg`), цвет задаем токеном через `currentColor`. Набирать логотип шрифтом нельзя (CLAUDE.md).

Файлы темы (`wp-content/themes/amour/assets/brand/`) собирает скрипт. Он убирает фон, ставит `currentColor`, обрезает рамку у больших слов и убирает лишние точки контура. Запускать после обновления пакета:

```bash
python3 bin/build-brand.py
```

**Вес (25.11.2026, с согласия Костянтина):** в мастерах контур записан очень частыми точками, до 18 000 на логотип. Вместе логотипы весили 650 КБ и задерживали первый экран на телефоне. Скрипт сборки оставляет только точки, которые видно: контур сдвигается меньше чем на 0,06 px на самом большом размере на сайте. Допуск для каждого файла записан в `bin/build-brand.py`. Логотипы стали весить ≈180 КБ. При попиксельном сравнении на двойной плотности экрана отличается только сглаживание краев. Мастера в этой папке не меняются.

Узор `pattern-eudora-jug-field.svg` (футер виллы) нарисован на холсте, в пакете его нет — проверить при сборке виллы (неделя 3).
