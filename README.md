# Сайт Amour Relax Hotel + Villa Eudora: пакет для сборки

Claude Code собирает по готовым макетам собственную тему WordPress. Код и автотесты лежат на GitHub (твой личный аккаунт, публичный репозиторий с 19.11.2026). Сам сайт живет на текущем хостинге amourrelaxhotel.com: сначала тестовая копия на поддомене, при запуске — основной домен.

## Локальная копия сайта
Нужны Docker Desktop (запущен), Node.js, PHP и Composer.

```bash
npm install && composer install
```
```bash
npm run wp:start
```

Первый запуск занимает несколько минут. Сайт: http://localhost:8888, админка: http://localhost:8888/wp-admin (стандартный вход wp-env: `admin` / `password`, только для копии на своем Mac). Команда сама создает страницы, меню, языки EN/DE и загружает фото с alt из `assets/manifest.csv`.

- `npm run check` — все проверки: код (PHP, JS, CSS и правила бренда) и тесты сайта.
- `npm run wp:stop` — остановить; `npm run wp:reset` — начать с чистой базы.

## Если меняется дизайн
Мелкие правки (текст, отступ, цвет кнопки) пиши сразу Claude Code. Крупные (новый блок, другая раскладка) сначала делаем на холсте с макетами, потом отдаем в сборку.

## Что внутри
| Папка или файл | Что это |
|---|---|
| `CLAUDE.md` | Правила для Claude Code: где что лежит, правила бренда, как работать, когда готово. Claude Code читает его сам при запуске в этой папке |
| `HANDOFF.md` | Техническое задание: стек, страницы, токены, компоненты, бронь, формы, админка, доступность, тесты, этапы по неделям, GitHub и тестовые версии |
| `design/boards` | 18 досок с холста — точные макеты всех страниц и меню |
| `prototype/Amour-site-prototype.html` | Прототип всех страниц в одном файле, открывается в браузере |
| `screens/` | Эталонные скриншоты: компьютер 1440×900 и телефон 390×844 |
| `design/ds`, `design/css`, `design/js` | Токены, стили, анимации |
| `design/generators` | Данные номеров, виллы и служебных страниц |
| `assets/` | 57 картинок, видео и SVG с понятными именами, `manifest.csv`, шрифты с лицензиями |
| `docs/` | Бренд-мануал, решения и открытые вопросы, аудиты, список заглушек |

## Что важно помнить
- Сайт, хостинг, домен и аккаунты аналитики — на компанию. GitHub — твой личный, только для кода и тестов.
- Пароли, ключи и коды в файлы и в чат с Claude Code не вставлять.
- Репозиторий публичный: его видят все. Внутреннее (номера аккаунтов, бюджет, переписка, данные гостей) — только в папке `private/`, она в GitHub не попадает. Полная версия дока 09 и этого README лежит там же.
- Квадратные скобки в макетах — заглушки. Их заполняем в админке при наполнении, не выдумываем.
- Фото мест в гиде, спален виллы и барбекю — временные, отмечены в `assets/manifest.csv`.
